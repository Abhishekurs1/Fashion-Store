# FashionStore

A full-stack e-commerce web application developed using Java, JSP, Servlets, JDBC, and MySQL.

## Features

- User Registration & Login
- Product Listing
- Shopping Cart
- Checkout
- Order Management
- Responsive UI

## Technologies Used

- Java
- JSP
- Servlets
- JDBC
- MySQL
- HTML
- CSS
- JavaScript
- Apache Tomcat

## How to Run

1. Clone the repository
2. Import into Eclipse
3. Configure MySQL
4. Run on Apache Tomcat
